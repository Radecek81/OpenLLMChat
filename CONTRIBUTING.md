# Contributing

Thank you for helping improve Open LLM chat.

1. Create a focused branch from the default branch.
2. Keep provider-specific behavior behind configuration or an adapter; do not add private infrastructure defaults.
3. Never commit API keys, conversation data, local `.env` files, or build artifacts.
4. Add or update tests for behavior changes.
5. Run the checks from the README before opening a pull request.

For security issues, follow `SECURITY.md` instead of opening a public issue.
