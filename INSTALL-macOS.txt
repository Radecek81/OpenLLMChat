Instalace na macOS
------------------

Balíček:
- Otevři `llm-chat-macos.dmg`
- Přetáhni `Open LLM chat.app` do `Applications`

První spuštění:
- Vývojový balíček je podepsaný ad-hoc; pro veřejnou distribuci je potřeba Developer ID podpis a notarizace
- Jde o nativní SwiftUI aplikaci pro macOS, nic se neinstaluje do Pythonu a neotevírá se prohlížeč

Poznámky:
- Konverzace a nastavení se ukládají do `~/Library/Application Support/LLM Chat Swift`
- URL, model i API klíč LLM můžeš měnit přímo v záhlaví aplikace
- Použité URL se ukládají do rozbalovacího seznamu stejně jako modely
- Pole `LLM model` zůstává editovatelné; jakmile model použiješ, uloží se do rozbalovacího seznamu
- V seznamech uložených URL a modelů je vlevo ikona koše pro odstranění konkrétní položky
- Tlačítko `DEBUG` otevře zprava poloprůhledné podokno se zeleným logem komunikace s LLM
- Tlačítko `Pokročilé` / `Advanced` otevře postranní panel pro `max_tokens`, kompresi a simulaci zaplnění
- Jazyk aplikace se volí automaticky podle macOS: čeština jen při českém prostředí, jinak angličtina
- Výchozí konfigurace je prázdná; zadej URL, model a případně API klíč svého poskytovatele
- Uložené API klíče jsou v macOS Keychainu, ne v `settings.json`
- V záhlaví je přepínač `Myšlení`, který posílá `chat_template_kwargs.enable_thinking`
- Bez `Myšlení` aplikace používá `max_tokens=4096`, s `Myšlení` `max_tokens=8192`
- Výchozí timeout pro LLM odpověď je 15 minut
- Přílohy se ukládají vedle konverzace do podsložky `conversations/<id>/files`
